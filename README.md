# PipelinePulse ⚡

> Know Your Pipeline. Close More Deals.

PipelinePulse is a B2B SaaS tool built for sales teams that automatically fetches open deals from HubSpot CRM and delivers a formatted daily summary directly to Slack — powered by Fastn.

---

## 🚀 What It Does

- Connects HubSpot CRM and Slack in one click
- Automatically fetches all open deals from HubSpot
- Formats a clean summary with deal name, amount, stage, and close date
- Posts the summary to your Slack channel instantly
- Embedded Fastn Widget for seamless integration management

---

## 🛠️ Built With

- **Fastn** — Integration platform powering HubSpot + Slack workflows
- **Node.js + Express** — Backend server for secure token generation
- **HubSpot CRM** — Source of open deals data
- **Slack** — Destination for automated deal summaries
- **HTML + CSS + JavaScript** — Frontend web application
